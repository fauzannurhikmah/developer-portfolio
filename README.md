# Alex Pratama — Cinematic Systems Architect Portfolio

Portofolio web berstandar bioskop digital (cinematic), modern, dan outstanding untuk Senior Full-Stack & Systems Architect. Didesain secara khusus untuk melepaskan diri dari tampilan template generic buatan AI, menghadirkan estetika *high-end obsidian & titanium*, pencahayaan anamorphic flare, audio synthesizer tactile berbasis Web Audio API, serta simulasi interaktif live telemetry real-time.

---

## 🌟 Sorotan Desain & Arsitektur (Anti-Generic AI)

1. **Atmosfer & Pencahayaan Sinematik (Anamorphic Grading)**:
   - Palet warna obsidian murni (`#05070c`), bevel titanium specular (`inset 0 1px 0 rgba(255,255,255,0.15)`), serta aksen pencahayaan tungsten amber dan cyan hyperion.
   - Lapisan tekstur **Film Grain 35mm** menggunakan filter SVG procedural `<feTurbulence>` untuk menghilangkan efek plastik *color banding*.
   - **Interactive Spotlight & 3D Tilt**: Kartu bereaksi terhadap posisi kursor dengan rotasi perspektif 3D yang halus.

2. **Tipografi Editorial Kelas Atas**:
   - **Syne**: Font display geometris modern bertaraf haute-couture untuk tajuk editorial berbobot tinggi.
   - **Plus Jakarta Sans**: Font sans-serif kontemporer dengan tingkat legibilitas optimal.
   - **JetBrains Mono**: Presisi teknis untuk metrik telemetry, kode, dan koordinat satelit.

3. **Neural Architecture Terminal Interaktif (`terminal.sh`)**:
   - Konsol terminal nyata yang dapat menerima perintah pengunjung: `help`, `architecture`, `benchmarks`, `stack`, `projects`, `contact`, `ping`, `neofetch`, `matrix`, `clear`.
   - Tab spec jaringan (`topology.spec`) dan radar konfigurasi arsitektur (`tech-radar.json`).
   - Quick command chips untuk akses satu kali klik.

4. **Simulasi Interaktif Proyek Unggulan (Bukan Mockup Statis)**:
   - **CloudMesh Observability**: Canvas osiloskop gelombang frekuensi telemetri real-time dengan status cluster live.
   - **OmniPay Settlement Gateway**: Visualisasi alur settlement terdistribusi, counter TPS dinamis, dan verifikasi hash kriptografi live.
   - **NexusFlow Workflow Orchestrator**: Diagram node graf interaktif dengan animasi transmisi paket energi berarah.
   - **HyperCanvas CRDT Engine**: Canvas gambar vektor kolaboratif dengan simulasi multi-user cursor tags dan pelacak koordinat mouse.

5. **Audio Synthesizer Haptic (Web Audio API)**:
   - Synthesizer suara klik dan dengungan sci-fi murni tanpa file MP3/WAV eksternal. Dapat dinyalakan/dimatikan kapan saja melalui tombol equalizer HUD di navbar.

6. **Command Palette HUD (`⌘K` / `Ctrl+K`)**:
   - Modal pencarian cepat untuk navigasi instan antar seksi, toggle audio, copy email satu klik, dan easter egg mode matrix.
